# Cassell Cleaners website

Static website files for the homepage and shop page.

## GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The site will be served from the root `index.html` file.

Product details and checkout buttons link to the official Cassell Cleaners store. Product prices and availability may change there.
